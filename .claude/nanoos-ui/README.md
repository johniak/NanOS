# NanoOS UI Concept

Statyczny prototyp interfejsu NanoOS w jednym pliku HTML.

## Zmiany w tej wersji

- Dolny dock zostaje w stylu pierwszego konceptu.
- Górny pasek działa jak globalne menu macOS: nazwa aktywnej aplikacji + File/Edit/View/Go/Window/Help.
- Menu aplikacji jest na górze, a nie w belkach okien.
- Okna mają bardziej windowsowe belki: tytuł po lewej, kontrolki po prawej.
- Projekt nie używa zewnętrznych bibliotek ani assetów.

Otwórz `index.html` w przeglądarce.
